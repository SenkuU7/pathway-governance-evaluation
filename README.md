# Pathway Governance Scenario Evaluation

This repository contains reproducibility materials for the scenario-based evaluation of pathway governance.

## Evaluation components

The evaluation includes:

- 60 governance-gate cases across licensing, social assistance, and public procurement
- 12 matched infrastructure-selection scenarios
- 6 paired checks
- 17 cross-domain checks
- 9 faulty governance-gate variants
- 6 infrastructure-selection sensitivity checks
- 4 faulty infrastructure-selection variants

## Notebook

`Pathway_Governance_Scenario_Evaluation.ipynb`

The notebook contains the scenario inputs, evaluation logic, expected outputs, observed outputs, and sensitivity checks used in the study.

## Evaluation boundary

The materials support traceability and reproducibility of the specified evaluation logic. Independent institutional validity, legal fit, exhaustive fault coverage, and deployed-system performance require separate evaluation.
